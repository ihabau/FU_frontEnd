## Key concepts
| Concept | Definition |
|---|---|
| **`<nav>`** | Semantic element for navigation links |
| **`<footer>`** | Semantic element for page footer |
| **Media query** | CSS rule that applies styles at specific screen widths |
| **`@media`** | CSS at-rule for responsive breakpoints |
| **Responsive design** | Page adapts to different screen sizes |
